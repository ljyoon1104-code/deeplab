# 로컬 학습 기록 초기화와 5173 포트 고정

확인일: 2026-10-17

## 대상과 실제 초기화

사용자가 Edge를 지정하고 삭제 직전에 두 주소의 앱 기록 삭제를 확인한 뒤, 정상 UI의 초기화 버튼으로 실행했습니다.

- `http://localhost:5173/deeplab/`
- `http://localhost:5174/deeplab/`

초기화 범위는 이 앱의 STEP 위치·완료 기록·저장된 실습 답안과 선택·MNIST 실험 기록입니다. GitHub Pages 운영 사이트, Codex 내장 브라우저, 다른 앱의 데이터는 초기화하지 않았습니다.

기존 초기화 함수는 진행 기록과 완료 버전 두 항목만 삭제했습니다. 이번에는 현재 주소의 `deep-learning-lab:`으로 시작하는 저장 항목을 수집한 뒤 삭제하도록 바꿨습니다. 저장 키 이름, 완료 버전, 계산·채점·완료 조건은 변경하지 않았습니다. 확인창과 Home 안내에도 실제 삭제 범위를 표시했습니다.

## 포트 고정

- `실행.bat`의 5174 재사용 분기를 제거했습니다.
- npm·pnpm 실행 인자에 `--port 5173 --strictPort`를 명시했습니다.
- Vite 기본 설정에도 `server.port: 5173`, `server.strictPort: true`를 추가해 일반 개발 명령의 자동 포트 변경을 막았습니다.
- 기존 5173 앱이 실행 중이면 배치 파일은 그 주소를 엽니다. 다른 프로그램이 점유하면 다른 포트로 이동하지 않고 서버 시작 오류를 표시합니다. 다른 프로그램을 강제 종료하지 않습니다.
- 사용 중인 5173에 두 번째 서버를 실행해 `Port 5173 is already in use`와 종료 코드 1을 확인했습니다. 이는 의도한 충돌 차단 결과입니다.

처음 확인할 때 5174는 실행 중이 아니었습니다. Edge에 남은 해당 주소의 기록에 접근하기 위해 일시적으로 5174 서버를 띄웠고, 초기화·새로고침 확인 후 종료했습니다. 종료 후 리스닝 상태는 기존 5173 서버만 확인됐습니다.

## 코드 검사와 한계

- 별도 메모리 저장소에서 현재 사용하는 앱 기록 11종 제거, 다른 접두사의 데이터 보존, 별도 주소 저장소 보존, 반복 초기화, 저장소 접근 제한 처리를 확인했습니다. 이 검사는 실제 사용자 브라우저 저장소를 사용하지 않았습니다.
- TypeScript·Vite 프로덕션 빌드·공백 검사 통과. 기존 대형 청크 경고는 남아 있습니다.
- 배치 파일 더블클릭부터 패키지 최초 설치까지 전 경로를 새 환경에서 실행한 것은 아닙니다. 실행 인자·설정·실제 포트 충돌 차단을 확인했습니다.
- 전체 84개 STEP 재완주는 수행하지 않았습니다. 커밋·push·운영 재배포는 하지 않았습니다.
