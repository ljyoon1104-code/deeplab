## 검증 시점과 한계

보고서의 과거 진단·미검증 문구·작업 경로는 당시 기록입니다. 뒤에 확인한 결과로 이전 기록을 덮어쓰지 않았습니다. 최신 확인 범위는 후속 보고서의 8절을 우선 보세요.

- 필수 경로 전체 완주·복원과 MNIST 학습·평가·Canvas·실험 비교는 기존 실행 기록입니다. 이번 문서 정리에서 다시 실행하지 않았습니다.
- 이후 MNIST 취소·재실행은 실제 브라우저 실행으로 추가 확인했습니다. 오류 재시도·오분류 0개 분기는 별도 통제 테스트이며 실제 모델 성능이나 브라우저 레이아웃의 근거가 아닙니다.
- 실제 200% 확대·reduced-motion 환경 적용·터치 입력·특수 분기의 실제 브라우저 표시와 과거 Provider HMR 오류의 정확한 원인은 미검증 또는 미확정으로 남아 있습니다.
- 전체 필수 경로 완주는 모든 선택 복습·모든 답안 조합·학생 대상 학습 효과 검증을 뜻하지 않습니다.
