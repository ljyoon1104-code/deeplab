# Lesson 11–12 학습 요소 대응표 (2026-10-17)

## 실제 렌더링과 보호 범위

- `Lesson11.tsx` → `StudyProvider` → `lesson11/StudySteps.tsx` (7개 STEP).
- `Lesson12.tsx` → 같은 `StudyProvider` → `lesson12/StudySteps.tsx` (7개 STEP).
- 이전 `Lesson11Steps.tsx`, `Lesson12Steps.tsx`는 현재 렌더링 대상이 아닙니다.
- 기존 `studyTasks.ts` 문항·ID·정답, 계산 함수, 저장 키/버전/형식과 완료 판정은 변경하지 않습니다. 설명 상태만 지역 상태로 둡니다.
- 각 STEP은 숨겨도 마운트를 유지합니다. 답안은 기존 Provider에 두고, 설명 장면·후보판 위치는 저장하지 않습니다.

## 공통 화면 원칙

대표 그림·핵심 계산은 기본 화면에 둡니다. 조작·입력과 피드백을 같은 영역에 배치합니다. 같은 설명을 반복하기보다 값의 출처와 의미를 수식 옆에 둡니다. 설명 탐색과 답 제출은 구분하며, 새 방문·클릭 완료 조건을 만들지 않습니다. 색 외에 단어·행·칸 번호를 표시합니다.

## 구현 후 재점검

위 14개 STEP을 실제 렌더링과 대조했습니다. 기존 `studyTasks`의 문항·선택지·정답·ID, `embeddingTrainingMath`의 평균/점수/확률/손실/역전파, Provider의 저장·채점·완료 판정은 변경하지 않았습니다. 새 필수 클릭이나 방문 조건은 없습니다.

- 11 STEP 4는 표현 비교·행렬 학습·단어 관계의 세 관찰 영역으로 나눴습니다. 숨긴 영역을 해제하지 않고 유지하며, 남은 문제 이동은 해당 영역을 엽니다. 행렬→세 벡터 평균→점수/확률→손실→기울기/학습률 수정은 기본 화면에서 이어집니다. 상세 미분 규칙만 보충입니다.
- 11 STEP 1·2·5·6·7과 12 STEP 1–7의 기존 질문을 해당 예시·입력·판단 그림 가까이 옮겼습니다. 독립 답의 기존 공개 조건은 유지했습니다.
- 12 STEP 6은 같은 후보판의 첫/둘째 단계가 바뀝니다. 기존 우유·TV·버스의 후속 후보, 선택·제출 값과 첫 선택 변경 시 후속 선택 초기화 동작은 유지합니다. 마지막 제출 결과와 현재 관찰 중인 후보판을 구별합니다.
- 임베딩 모형의 12개 파라미터에 대한 수치 미분과 기존 해석 기울기의 최대 차이는 약 1.05×10⁻¹⁰입니다. 계산 파일 자체는 변경하지 않았습니다.
- 실제 테스트 origin에서 임베딩 오답→새로고침 복원→수정 제출, 설명 왕복 후 답안 유지, 세 생성 분기와 후속 제출, RNN 5개 설명과 다시 보기를 확인했습니다. 전체 14 STEP의 모든 답안을 다시 풀었다는 뜻은 아닙니다.
