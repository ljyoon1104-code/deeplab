# Lesson 11 임베딩 현재 처리 장면 정리

## 범위와 대응

실제 경로: `Lesson11 → StudySteps.Lesson11Step4 → EmbeddingVisualizer → EmbeddingTraining`.
표현 비교와 단어 간 관계는 기존 `EmbeddingVisualizer`에 남기고, 가운데 학습 그림만 재구성합니다.

| 기존 학습 요소 | 새 기본 학습 위치 |
| --- | --- |
| 행·열·인덱스·차원·초기값, 숫자 의미 | 1. 행렬 준비 |
| 세 단어의 행 가져오기, 선택 행의 관찰 의미 | 2. 세 벡터 가져오기 |
| 같은 칸의 평균, 모델 입력, 순서 처리 한계 | 3. 칸별 평균 |
| 입력 h·가중치 W·편향 b, 점수 z, 소프트맥스 중간값·확률 | 4. 점수와 확률 |
| 학습 자료의 다음 단어, 후보 확률, CCEE·손실의 뜻 | 5. 자료와 손실 비교 |
| 역전파·기울기·학습률, E·W·b의 실제 수정 규칙 | 6. 현재 값 수정 |
| 같은 칸 전후 비교, 새 평균·점수·확률·손실, 반복 학습의 의미와 한계 | 7. 수정 후 재예측 |
| 원-핫×행렬 보조 계산 | 2번 장면의 선택 보충 설명 |
| 조회·학습·유사성 독립 문항 | 기존 Question·ID·Provider·완료 판정 그대로 |

기존의 긴 전체 계산 화면에서 설명·테두리만 바꾸던 5단계를, 입력·계산·결과·이유가 실제로 바뀌는 7장면으로 나눕니다. 단계 이동은 현재 장면 바로 위에 둡니다. 핵심 계산을 접힌 영역으로 이동하지 않습니다.

## 보호 범위

- `embeddingTrainingMath.ts`, 문항, Provider, 답안·완료·저장 코드를 수정하지 않습니다.
- `EMBEDDING_DEMO`의 한 번 계산된 전후 기록만 표시합니다. 설명 이동·관찰 대상 변경은 추가 학습이 아닙니다.
- 독립 문항 children은 장면 조건부 렌더링 밖에 유지하여 설명 이동으로 문항이 해제되지 않게 합니다.
- 실제 화면·전체 타입·빌드는 통합 검증 담당이 확인합니다.

## 구현 후 정적 확인

- 변경 파일: `src/lessons/lesson11/EmbeddingTraining.tsx`, 이 대응 문서. 다른 Lesson 11 파일과 기존 계산 모듈은 이번 담당 작업에서 수정하지 않았습니다.
- TSX 구문 검사 오류 0. `git diff --check -- src/lessons/lesson11` 오류 없음(LF/CRLF 안내만 발생). 미추적 대상 파일의 줄 끝 공백·최종 줄바꿈도 직접 검사했습니다.
- 표시 계산 대조: 초기 평균 `[0.066666…, 0.033333…]`, 수정 후 `[0.0537026…, 0.0462973…]`; 손실 `0.8110356… → 0.7409863…`. 화면의 평균·소프트맥스·손실·E/W/b 갱신식이 기존 계산 결과와 오차 `1e-14` 이내로 일치했습니다. 행렬 크기 3×2 유지.
- 단계·관찰 행·칸·파라미터 선택은 지역 상태뿐이며, 재학습 함수나 답안 갱신 함수를 호출하지 않습니다. 독립 문항 ID·정답·완료 조건 및 기존 완료 기록을 변경하지 않았습니다.
- 브라우저 검증 경로: Lesson 11 STEP 4 → ‘② 행렬로 학습’ → 관찰할 처리 1~7. 6번에서 E/W/b 대상 변경, 7번에서 관찰 행 변경과 전후 평균·손실 고정 여부를 확인합니다. 실제 모바일·키보드·답안 복원 검증은 통합 담당 결과와 구분합니다.
