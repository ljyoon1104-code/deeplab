# Lesson 01~04 학습 요소 대응표

작성: 2026-10-17. 구현 전 실제 렌더 경로와 28개 STEP을 조사한 뒤 작성했습니다. 이번 작업은 기존 계산·문항·완료 판정·저장을 바꾸지 않고, 같은 입력·그림·조작·피드백을 가까이 묶습니다.

## 실제 경로와 상태 계약

- `Lesson01.tsx`~`Lesson04.tsx` → 각 `LessonXXSteps.tsx`의 7개 STEP. 사용하지 않는 예전 컴포넌트만 수정하지 않습니다.
- 차시 래퍼는 모든 STEP을 마운트하고 `hidden`으로 전환합니다. 종합 STEP의 소구간·문제도 기존 `hidden` 방식을 유지합니다.
- 답안·제출·관찰은 기존 각 STEP의 React 상태이며, STEP 완료·차시 완료는 기존 공통 진행도에 기록됩니다. 답안이나 기존 완료 이력을 새 구조로 이관하지 않습니다.
- 계산 보호: `perceptronMath.ts`, `activationMath.ts`, `networkMath.ts`. 데이터·정답·허용 오차와 완료 조건은 유지합니다.
- 교과서 근거는 기존 `docs/planning/learning-redesign-stage1.md`의 T1~T4(인쇄 91~96 / PDF 38~43)를 재사용합니다. 원문 재확인은 통합 담당의 별도 결과와 구분합니다.

## 구현·검증 기록

대응표에 적은 필수 내용은 기본 학습 경로에 남깁니다. 새 필수 클릭·방문·설명 시청을 추가하지 않습니다. 구현 후 실제 변경 파일·정적 검사와 대표 화면 검증 결과를 이어 기록합니다.

### 구현 후 누락 점검

- 28개 STEP과 그 필수 활동을 대응표에 다시 대조했습니다. 기존 문항·선택지·예제·해석·제출 조건은 유지했습니다. 내용이 이미 입력·조작·피드백으로 잘 묶인 STEP은 추가 카드나 새 문항을 만들지 않았습니다.
- L01-1·3·5: 기존 분류 목록을 번호 탐색 → 현재 문장 → 현재 선택/분류 버튼으로 정리했습니다. 모든 문장을 그대로 선택하고 분류하며, 다른 문장으로 이동해도 기존 `assignments`를 유지합니다.
- L02-2: 완성 계산의 중복된 별도 숫자 목록을 제거하고 같은 `textbookResult`를 사용하는 그림과 단계별 계산에 통합했습니다. 단계별 이유는 모두 기본 화면에 있습니다. 계산 이름 직접 선택과 행동 이름을 붙인 전후 이동은 설명 상태만 바꿉니다.
- L02-7: 다섯 문제는 각각 `hidden`으로 표시를 전환합니다. 기존 답안·제출 배열과 전체 완료 판정은 유지했습니다.
- L03-1·4: 활성화가 필요한 이유와 시그모이드 계산식/기호를 기본 화면으로 꺼냈습니다. 지수 계산을 새 필수 과제로 요구하지 않습니다.
- L03-6: 각 클래스의 점수 슬라이더, 실제 소프트맥스 확률, 막대와 반올림 전 값을 한 행에 배치했습니다. 관찰·이유 제출·계산·반올림 방식은 그대로입니다.
- L04-2: 층별 역할·그림·확인 버튼을 한 카드로 묶었습니다. 기존 세 층 방문과 뉴런 수 판단을 그대로 유지했습니다. 다른 구조 그림은 새 선택 인자를 전달하지 않으므로 기존 표시를 유지합니다.
- L04-3·4: 각 뉴런의 수식 아래에 기존 답안란과 필드별 피드백을 옮겼습니다. 학생 입력값을 계산식 정답처럼 사용하지 않고 기존 정답 조건 전까지 `?`를 유지합니다. 설명 조작은 그림 가까이에 배치했습니다.

- 실제 브라우저·키보드·새로고침 검증은 통합 담당에서 별도로 기록합니다. 본 정적 검사만으로 UI 통과를 주장하지 않습니다.
