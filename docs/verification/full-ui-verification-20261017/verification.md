## 발견 사항과 미검증

1. **React 중복 key 로그 — 원인 미특정.** 검증 탭의 error 로그에서 `Encountered two children with the same key ... 0` 확인(2026-10-16 17:42:57–17:44:26 UTC, 조회한25건). 로그 소스는 react-dom_client.js이며 발생 차시·STEP/컴포넌트 스택은 이 기록만으로 특정할 수 없습니다. 활동 진행을 막은 장면은 관찰하지 못했습니다. 새로고침 전후 차이를 이 경고에 연결할 근거도 없습니다. 현재 콘솔 오류 ‘없음’으로 처리하지 않으며 수정하지 않았습니다.
2. **완료 기록과 임시 답안 안내의 차이 — UI 혼동 가능.** L01 완료→새로고침→STEP7에서 차시는100%/완료지만 지역 프로젝트·문제 답안은 초기화되어 소구간 ‘○ 남음’ 표시. L10 서비스에서도 유사. 기존 설계대로 임시 상태가 초기화된 것이며 완료 기록 복원 실패가 아닙니다. 진행 차단 없음. 기대되는 개선 여부는 별도 판단이 필요하며 이번에 수정하지 않았습니다.
3. **L08 STEP6 직접 그린 숫자의 실제 예측 미검증.** 사용 가능한 IAB의 문서화된 API가 연속 포인터 드로잉을 제공하지 않습니다. Canvas 이벤트/픽셀을 프로그램으로 주입하지 않았습니다. 결과적으로 해당STEP·차시완료·12/12전체완료 복원은 미검증입니다. 빈 입력 차단은 확인했습니다.
